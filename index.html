🧩 Arquitetura Multiagente

      

        LoaderAgent: valida ZIP, extrai CSVs via JSZip, detecta encoding, usa PapaParse.


        SchemaAgent: infere tipos (numérico, data, categórico), estatísticas, cria dicionário, mapeia sinônimos PT-BR (fornecedor→emitente, valor→vNF, produto→xProd etc).


        QueryAgent: NLU híbrido - tenta Claude API (se rodando em sandbox) senão heurística + embeddings locais. Gera QueryPlan Pydantic-validado: {intent, metric, group_by, order, limit, filters, viz_hint}.


        ExecutorAgent: executa apenas operações whitelist (sum, avg, count, count_distinct, max, min, group_sum, growth). Sem eval de código.


        VizAgent: decide entre text/table/bar/line/pie e renderiza Chart.js.


        FallbackAgent: mensagens claras, sugestão de reformulação, lista colunas relevantes, nunca quebra.
        

          LOADER→SCHEMA→QUERY→EXECUTOR→VIZ→FALLBACK
